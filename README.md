# 만자천홍 부대 편성실

파이어 엠블렘 만자천홍(万紫千紅)의 4개 루트(카이·디트리히·세오도라·레다) 부대를 편성하고, 루트별 빌드와 부대 구성을 한눈에 확인하는 개인용 플래너입니다.

## 사용

GitHub Pages 주소를 PC나 모바일 브라우저에서 열면 됩니다. 로그인·설치·빌드는 필요 없습니다.

- **루트별 영입 조건**: 루트 탭의 캐릭터 목록에는 그 루트에서 영입할 수 있는 캐릭터만 나오고, 이름 아래에 필요한 명성·지원이 표시됩니다. 캐릭터를 누르면 추가 조건(골드, 아이템, 부탁, 외전, 문답), 주의사항, 달성 방법이 나옵니다. `전체 보기`로 영입 불가 캐릭터도 볼 수 있고, `필요 명성 순`으로 정렬할 수 있습니다.
- **영입 스케줄**: 선택한 루트에서 부대에 편성한 캐릭터(또는 영입 가능 전체)를 필요 명성 순으로 묶어 지원·명성·조건·주의사항·방법·좋아하는 선물을 보여주고, 필요한 골드 합계·아이템·부탁·외전·문답 정답을 준비물 요약으로 모아 줍니다.
- **캐릭터 검색**: 이름, 초성(`ㄷㅌㄹㅎ`), 특성으로 찾고 배정 상태·물리/마법/활/기병 등 빠른 필터와 상세 필터, 성장률 정렬을 사용할 수 있습니다. PC에서는 `/` 키로 검색창에 바로 이동합니다.
- **루트 탭 (1+2부)**: 카이·디트리히·세오도라·레다 루트마다 1부와 2부를 이어서 쓰는 부대와 빌드를 관리합니다. 최종직은 2부까지 열리는 상급직 이하에서 고릅니다.
- **3부 통합 탭**: 루트가 합쳐지는 3부용 명단입니다. 1+2부에서 배정한 동료를 한 번에 불러와 각 캐릭터 줄의 1~5·대기 버튼으로 부대(각 최대 8명)를 바로 고르고, 최종장 출격 25명을 ★로 표시합니다. 캐릭터마다 3부 최종직(최상급직)을 따로 정하고, 인과 융합 참고용으로 1+2부 루트별 직업을 함께 보여줍니다. 분석은 전체·부대별·최종장 범위로 볼 수 있습니다.
- **부대 편성**: 목록의 `+`로 현재 루트에 추가합니다. PC에서는 목록에서 부대로 끌어다 놓을 수 있고, 부대 안의 순서는 왼쪽 손잡이를 끌어 바꿉니다(모바일 터치 지원). 제외는 `되돌리기` 또는 `Ctrl+Z`로 취소할 수 있습니다.
- **캐릭터 상세 / 빌드**: 캐릭터를 누르면 성장률·특기·약점·특성·영입 조건과 루트별 빌드(역할, 최종직, 주·보조무기, 이동 타입, 전직 경로, 메모)가 한 화면에 열립니다. 최종직을 고르면 이동 타입이 자동으로 정해지고, 무기는 그 병종이 쓸 수 있는 것만 고를 수 있습니다. 성장률에는 최종직 보정을 합산해 볼 수 있습니다.
- **부대 분석**: 역할·무기·이동 타입·최종직 분포와 겹침(최종직 2명 이상, 역할·무기 4명 이상)을 표시합니다. 좋고 나쁨을 판정하지는 않습니다.
- **루트 비교**: 4개 루트(1+2부)의 인원·구성 비교표, 여러 루트에 배치한 캐릭터, 미배정 캐릭터와 3부 명단 요약을 보여줍니다.
- **후보 비교**: 최대 3명의 성장률·특기·특성을 나란히 비교합니다.

편성·빌드·메모는 브라우저에 자동 저장됩니다.

## 기기 간 동기화

`설정 → 기기 간 동기화`에서 GitHub 토큰을 연결하면, 편성이 내 GitHub 계정의 **비공개 gist** 하나에 저장되고 같은 토큰을 연결한 모든 기기(PC·폰)에 자동으로 반영됩니다.

1. 설정의 `GitHub 토큰 만들기` 링크를 열면 gist 권한만 체크된 토큰 생성 화면이 나옵니다. 맨 아래 **Generate token**을 누르세요.
2. 만들어진 토큰(`ghp_…`)을 설정에 붙여넣고 `연결`을 누릅니다. 다른 기기에서도 같은 토큰으로 한 번씩 연결합니다.

- 수정하면 약 1.5초 뒤 자동으로 올라가고, 다른 기기는 화면을 열거나 다시 볼 때, 그리고 15초마다 변경을 받아옵니다.
- 두 기기에서 동기화 없이 따로 수정했다면 더 최근에 수정한 쪽으로 맞추며, `되돌리기`로 이전 상태를 복구할 수 있습니다.
- 토큰은 각 기기의 브라우저에만 저장되고 이 저장소나 다른 곳으로 보내지 않습니다. 기기를 잃어버렸다면 GitHub `Settings → Developer settings → Personal access tokens`에서 토큰을 삭제하세요.
- 연결하지 않아도 `설정 → 백업`의 JSON 내보내기·불러오기로 옮길 수 있습니다.

## 스포일러 보호

기본으로 1·2부에 합류하는 캐릭터와 초기 명단, 3부에 합류하는 1부 외전 주인공 4명(56명)만 보여줍니다. `설정 → 스포일러 보호`에서 전체 캐릭터를 표시할 수 있습니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 |
| `styles.css` | 화면 디자인(라이트/다크, PC·태블릿·모바일) |
| `app.js` | 화면 동작 |
| `core.js` | 저장 형식(버전 2, 버전 1 자동 변환), 부대 집계, 백업 검증 |
| `recruit.js` | 루트별 영입 조건 (명성·지원·추가 조건·주의사항·방법)과 아이템·외전·부탁·문답 요약 |
| `gifts.js` | 캐릭터별 좋아하는 선물 |
| `sync.js` | GitHub gist 동기화 |
| `catalog.js` | 캐릭터·병종·루트 초기 명단 데이터 |
| `portraits.js` | 초상화 이미지 |
| `fonts/pretendard/` | Pretendard 글꼴 (SIL Open Font License, `LICENSE.txt` 포함) |
| `tools/stamp-assets.mjs` | 파일 수정 후 캐시 갱신용 버전 값을 다시 계산 |

파일을 고친 뒤에는 `node tools/stamp-assets.mjs`를 실행해 `index.html`의 `?v=` 값을 갱신해야 방문자 브라우저가 새 파일을 받습니다.
