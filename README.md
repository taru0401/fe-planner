# 만자천홍 부대 편성실

한국어 개인 부대 편성·육성 플래너입니다. 카이·디트리히·세오도라·레다의 편성을 별도로 관리합니다.

## 사용

GitHub Pages 주소를 PC 또는 모바일 브라우저에서 열어 사용합니다. 저장되는 편성·빌드·메모는 각 브라우저 안에만 보관되며 서버로 전송하지 않습니다. 다른 브라우저나 기기로 옮기려면 `데이터 내보내기`로 저장한 JSON을 `백업 및 설정 → 데이터 불러오기`에서 적용하세요. 자동 기기 동기화는 없습니다.

초기 편성은 사용자 제공 명단입니다. 기본 공개는 1·2부 합류가 확인된 캐릭터와 초기 명단으로 제한합니다. 전체 공개는 설정에서 선택할 수 있습니다.

## 출처

- [cass07 만자천홍 데이터베이스](https://cass07.github.io/fe18-db/): 캐릭터·병종 성장률, 특성, 능력치 보정, 전직 요구치, 마스터 스킬
- [redfreshet 만자천홍 도구](https://redfreshet.com/game-tools/fe-banshisenko/): 특기·약점, 사용 무기, 이동 타입·이동력, 합류 시점 보완

자료 기준: 2026-09-28. 외부 자료원에는 스포일러가 있을 수 있습니다. 게임 및 원자료의 권리는 각 권리자에게 있습니다.

## Pages 설정

Settings → Pages → Deploy from a branch → main / (root) → Save.
앱 실행에는 별도 빌드, 패키지 설치, 로그인, API 키가 필요 없습니다.
